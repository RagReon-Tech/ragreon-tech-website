This folder contains the complete Google Apps Script code and manifest for the RagReon Tech client enquiry system.

- [`Code.gs`](file:///e:/RagReon/google-apps-script/Code.gs): Complete server-side code (handles `doGet`, `doPost`, `LockService`, input validation, formula injection sanitization, Google Sheets row appending, and Gmail notifications).
